# Protocol contract seed

This directory is a language-neutral design seed, not a published package.
`manifest.json` records the first captured sample and its expected normalized
meaning. The sample's provenance documents its URL, capture time, sanitization
and raw response hash. No live signed-in verification is implied.

Future Dart, Node and Python contract runners should consume a pinned contract
revision. Expected verdicts must follow independent evidence and explicit policy,
not be generated from whichever implementation currently passes its own tests.

See `docs/ECOSYSTEM-CONTRACTS.md` for boundaries and incremental adoption.
